## 🚀 Featured Project

### Crypto Tracker SaaS

A subscription-based cryptocurrency monitoring platform built with modern web technologies.

#### Features

* Google OAuth Authentication
* Supabase Auth Integration
* Stripe Subscription Payments
* CoinGecko API Integration
* Tier-Based Access Control
* Real-Time Cryptocurrency Monitoring
* Responsive Dashboard Experience

#### Subscription Plans

* Guest → 1 cryptocurrency
* Free User → 4 cryptocurrencies
* Premium → 10 cryptocurrencies
* VIP → 20 cryptocurrencies

#### Stack

Next.js • TypeScript • Prisma • Supabase • Neon PostgreSQL • Stripe • CoinGecko API
